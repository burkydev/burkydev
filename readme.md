### About Me

I'm **burkydev**, a developer and enthusiast interested in understanding how software works under the hood.

My interests revolve around game development ecosystems, game security, reverse engineering, and experimenting with different software technologies.

- Minecraft plugins and server-side systems
- FiveM scripts and development
- Anti-cheat research and analysis
- Reverse engineering and software analysis
- Source code exploration and tooling
- Security research and experimentation
